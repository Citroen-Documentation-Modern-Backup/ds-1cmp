B3FG01EVP0Dépose - Repose : Câbles de frein de stationnement
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débloquer les écrous de roue (Arrière).
Lever et caler le véhicule, roues arrière pendantes.
Déposer les roues arrière.
Desserrer le frein de stationnement .
Déposer :
  • La console centrale arrière
  • Les disques de freins arrière
  • Les moyeux arrière
  • Les segments de frein de stationnement
Figure : b3fg1gxd
Desserrer l’écrou (1).
Positionner l’écrou (1) à l’extrémité du filetage de la tige (2) (en "a").
Désaccoupler : L’extrémité des câbles de frein de stationnement (3) (en "b").
Dégager des guides les câbles de frein de stationnement (3) (en "c").
Soulever légèrement la moquette du tapis de plancher arrière (zone de passage des câbles de frein de stationnement).
1.1. Câble de frein de stationnement gauche
Figure : b3fg1h0d
Déposer :
  • Les écrous (6)
  • Le protecteur (7)
Déposer :
  • L’écrou (5)
  • La vis de fixation (4)
Dégager : L’anneau d’arrêt  (en "d").
1.2. Câble de frein de stationnement droit
Figure : b3fg1h3d
Déposer :
  • L’écrou (8)
  • La vis de fixation (9)
Dégager : L’anneau d’arrêt  (en "e").
1.3. Dépose (Suite)
Figure : b3fg1h4d
Déposer : Le clip d’arrêt (10) ( de chaque côté).
Dégager ( de chaque côté) :
  • Le câble de frein de stationnement (3) (en "f")
  • Le câble de frein de stationnement (3) du plateau de frein
Déposer chaque câble de frein de stationnement (3).
2. Repose
ATTENTION : Respecter les couples de serrage .
Soulever la moquette du tapis de plancher arrière.
Engager : Les câbles de frein de stationnement (3) (Dans le plancher de caisse).
Engager ( de chaque côté) :
  • Le câble de frein de stationnement (3) dans le plateau de frein
  • Le câble de frein de stationnement (3) (en "f")
Reposer : Le clip d’arrêt (10) ( de chaque côté).
2.1. Câble de frein de stationnement droit
Reposer :
  • La vis de fixation (9)
  • L’écrou (8)
  • L’anneau d’arrêt  (en "e")
2.2. Câble de frein de stationnement gauche
Reposer :
  • La vis de fixation (4)
  • L’écrou (5)
  • L’anneau d’arrêt  (en "d")
  • Le protecteur (7)
  • Les écrous (6)
Engager les câbles de frein de stationnement (3) dans leurs guides (en "c").
Accoupler : L’extrémité des câbles de frein de stationnement (3) (en "b").
2.3. Repose (Suite)
Reposer :
  • Les segments de frein de stationnement
  • Les moyeux arrière
  • Les disques de freins arrière
Régler le frein de stationnement .
Reposer :
  • La console centrale arrière
  • Les roues arrière
  • Les écrous de roues
  • Le véhicule sur ses roues
Serrer : Les écrous de roues .
