2. Dépose
Débrancher la batterie .
Figure : c5cm009d
Déclipper le cache (1) ( en "a") ; À l’aide de l’outil [1].
Figure : c5cm00ad
Déposer :
  • L’écrou (2)
  • Le bras d’essuie-vitre arrière (3) ; À l’aide de l’outil [2]
Déposer les garnitures de volet arrière .
Figure : c5dm01wd
Déconnecter le connecteur ( en "b").
Déposer :
  • Les vis (4)
  • Le mécanisme d’essuie-vitre arrière (5)
Figure : c5cm00bd
Déposer : Le joint d’étanchéité (6) (Vers l’extérieur) ; À l’aide de l’outil [1].
3. Repose
ATTENTION : Remplacer systématiquement le joint d’étanchéité .
ATTENTION : Avant la repose du bras d’essuie-vitre arrière, activer l’essuie-vitre arrière.
NOTA : Vérifier le fonctionnement électrique des différents équipements, avant de reposer les garnitures de volet arrière.
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • L’écrou (2) à 0,5 m.daN
  • Les vis (4) à 0,5 m.daN
Rebrancher la batterie.
