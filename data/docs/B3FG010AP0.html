B3FG010AP0Dépose - repose : Capteur de roue avant
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Débloquer les écrous de roue (avant).
Lever et caler le véhicule, roues avant pendantes.
Déposer :
  • Les écrous (Roue avant)
  • La roue avant
1.1. Capteur de roue avant (droit)
Figure : b1bm03pd
Déconnecter le connecteur  (en "a").
Dégrafer le faisceau du capteur de roue (en "b").
1.2. Capteur de roue avant gauche
Figure : b1bm03qd
Déposer les vis (1).
Dégrafer les agrafes (2) (en "c").
Figure : b1bm03rd
Déposer :
  • Le conduit d’air (3)
  • Le filtre à air (4)
Figure : b1bm03sd
Dégrafer le faisceau  (en "e", "f", "g", "h").
Déconnecter le connecteur du débitmètre d’air (en "d").
Desserrer le collier (5).
Déposer :
  • La vis (6)
  • Le boîtier d’air (7)
Figure : b1bm03td
Déconnecter le connecteur du capteur de roue (en "j").
1.3. Opérations communes
Figure : b3bm00ed
Déposer :
  • L’écrou (8)
  • La vis (9)
Dégrafer :
  • Le faisceau du capteur de vitesse de roue  (en "k", "l")
  • Le support du faisceau électrique (Capteur de roue) (en "m") (De chaque côté de l’amortisseur)
Déposer :
  • La vis (10)
  • Le capteur de roue (11)
2. Repose
ATTENTION : Ne pas placer un roulement avec roue magnétique intégrée à proximité d’une source magnétique ou d’une source de pollution par particules métalliques.
ATTENTION : Éviter les chocs sur la tête du capteur de roue.
2.1. Opérations communes
NOTA : Contrôler la propreté du capteur de roue (11).
Reposer :
  • Le capteur de roue (11)
  • La vis (10) ; Serrer à 0,9 ± 0,1 m.daN
NOTA : Respecter le cheminement du faisceau (Capteur de roue).
Agrafer :
  • Le support faisceau (Capteur de roue) (en "m") (De chaque côté de l’amortisseur)
  • Le faisceau du capteur de vitesse de roue  (en "l", "k")
Reposer :
  • La vis (9) ; Serrer à 1,1 ± 0,2 m.daN
  • L’écrou (8) ; Serrer à 1,1 ± 0,2 m.daN
2.2. Capteur de roue avant gauche
Connecter le connecteur du capteur de roue (en "j").
Reposer :
  • Le boîtier d’air (7)
  • La vis (6) ; Serrer à 0,9 ± 0,1 m.daN
Le collier (5): Serrer à 0,4 ± 0,1 m.daN.
Agrafer le faisceau (en "h","g", "f", "e").
Connecter le connecteur du débitmètre (en "d").
Reposer :
  • Le filtre à air (4)
  • Le conduit d’air (3)
Agrafer : Les agrafes (2) (en "c").
Reposer les vis (1).
2.3. Capteur de roue avant (droit)
Agrafer le faisceau du capteur de roue  (en "b").
Connecter le connecteur  (en "a").
2.4. Opérations communes
Reposer :
  • La roue avant
  • Les écrous (Roue avant)
Replacer le véhicule sur le sol.
Serrer les écrous à 10 ± 1 m.daN (Roue avant).
Effectuer une lecture des codes défauts ; À l’aide d’un outil de diagnostic.
