C5IG010DP0Dépose - repose : Sous-ensemble toit ouvrant
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap2xbd
[1] Pince pour dépose des pions plastique (-).7504-T.
2. Opérations préliminaires
Déposer la garniture de pavillon .
Rabattre : Les sièges avant.
Plier les sièges arrière .
3. Dépose
Figure : c5im01nd
Déposer (de chaque côté) :
  • Les vis (2)
  • Le renfort (1)
Figure : c5im01pd
Déconnecter les connecteurs  ("b", "c").
Déclipper les agrafes  (en "a"); À l’aide de l’outil [1].
Dégager les faisceaux électriques(4).
Déposer les écrous (3) (de chaque côté).
Figure : c5im01qd
Déposer l’écrou (5) (de chaque côté).
Dégager : Le clip (6) ; À l’aide d’une pince (de chaque côté).
Désaccoupler le tuyau d’écoulement d’eau arrière (7) de l’ensemble du toit ouvrant (8)(de chaque côté).
Figure : c5im01rd
Déposer l’écrou (9) (de chaque côté).
Dégager : Le clip (10) ; À l’aide d’une pince (de chaque côté).
Désaccoupler le tuyau d’écoulement avant (11) de l’ensemble de toit ouvrant (8)(de chaque côté).
Figure : c5im01sd
Déconnecter le connecteur  (en "d").
Déposer les écrous (12).
Figure : c5im01td
ATTENTION : 2 personnes sont nécessaires pour effectuer les opérations suivantes.
Couper : Les rivets (13) ; À l’aide d’un burin (de chaque côté).
Déposer (de chaque côté) :
  • La patte (14)
  • La rondelle (15)
Figure : c5im01ud
Déposer l’ensemble toit ouvrant (8) par le volet arrière .
4. Repose
Percer les corps des rivets (13) restants sur l’ensemble toit ouvrant (8).
Figure : c5im01zd
NOTA : Respecter le sens du montage du renfort (1) ; La flèche "e" doit être vers l’avant du véhicule.
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les vis (2) à 0,8 ± 0,3 m.daN
  • Les écrous (3), (5), (9), (12) à 0,8 ± 0,3 m.daN
ATTENTION : Vérifier le fonctionnement de la vitre de toit ouvrant avant de reposer la garniture .
Contrôler : Étanchéité toit ouvrant (voir opération correspondante).
Initialiser le motoréducteur de toit ouvrant (voir opération correspondante).
Reposer la garniture de pavillon .
Vérifier le fonctionnement des équipements électriques.
