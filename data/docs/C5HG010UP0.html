REFRIGERATION AUTOMATIQUE
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Opérations préliminaires
Débrancher la batterie .
Déposer :
  • La planche de bord
  • Le groupe de chauffage
2. Dépose
Figure : c5hm043d
Déposer le pion de fixation (1).
Désaccoupler le conduit d’air (2) (côté gauche).
Figure : c5hm044d
Déconnecter les connecteurs  (en "a") (suivant équipement).
Déposer :
  • Les 3 vis (3)
  • La platine de fixation aérotherme (4)
Figure : c5hm045d
Déposer l’aérotherme (5) (suivant "b").
3. Repose
Reposer :
  • L’aérotherme (5)
  • La platine de fixation aérotherme (4)
  • Les 3 vis (3)
Reconnecter les connecteurs  (en "a") (suivant équipement).
Accoupler le conduit d’air (2) (côté gauche).
Reposer :
  • Le pion de fixation (1)
  • Le groupe de chauffage
  • La planche de bord
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Vérifier le fonctionnement de l’aérotherme.
