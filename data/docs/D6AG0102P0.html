D6AG0102P0Dépose - repose : Faisceau arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Opérations préliminaires
Effectuer les opérations suivantes :
  • Couper le contact
  • Attendre 3 minutes avant de débrancher la batterie
  • Débrancher la batterie
Déposer :
  • Le pare-chocs arrière
  • Les garnitures d’aile arrière
3. Dépose
IMPERATIF : Avant dépose : Repérer le cheminement du faisceau électrique .
Figure : d6am00fd
Déconnecter les connecteurs du faisceau électrique (1) (Arrière ).
Déclipper :
  • Les agrafes du faisceau arrière (1)
  • Les lanières de bridage du faisceau (1) (Arrière )
Déposer le faisceau électrique (1) (Arrière ).
4. Repose
IMPERATIF : Remplacer systématiquement : Les lanières de bridage du faisceau / Les agrafes défectueuses.
IMPERATIF : Reposer le faisceau (1) suivant le cheminement repéré avant la dépose.
Reposer : Le faisceau (1) (Arrière ).
Clipper : Les agrafes et les lanières de bridages du faisceau arrière (1).
Connecter les connecteurs (Faisceau électrique arrière) (1).
Procéder dans l’ordre inverse des opérations de dépose.
Rebrancher la batterie.
Vérifier le fonctionnement électrique des équipements.
