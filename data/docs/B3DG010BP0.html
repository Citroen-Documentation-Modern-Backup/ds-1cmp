B3DG010BP0Dépose - repose : Bras inférieur de suspension (arrière)
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Lever et caler le véhicule, roues arrière pendantes.
Déposer : Le ressort de suspension .
Figure : b3dm01vd
1.1. Côté gauche
Déposer : Le réservoir d’additif de carburant .
Déposer vis (1).
Desserrer la vis (5).
Écarter : Barre de renfort (6).
1.2. Côté droit
Déposer vis (2).
Desserrer la vis (4).
Écarter : Barre de renfort (3).
1.3. Dépose (suite)
Attacher le bras supérieur de suspension à la caisse.
Figure : b3bm00ud
Déposer :
  • La vis (7)
  • Les vis (8)
  • Le bras inférieur de suspension (9)
2. Repose
Contrôler l’état :
  • Bras inférieur de suspension
  • Articulations élastiques du bras inférieur de suspension
Remplacer les pièces défectueuses (si nécessaire).
Reposer :
  • Le bras inférieur de suspension (9)
  • Les vis (8)
Positionner l’amortisseur arrière dans le bras inférieur de suspension arrière (9).
Reposer la vis ((7)).
Serrer :
  • Les vis (8) à 7,1 ± 1 m.daN
  • La vis (7) à 7,1 ± 1 m.daN
2.1. Côté gauche
Positionner : Barre de renfort (6).
Reposer la vis (1).
Serrer les vis (1), (5) à 1,1 ± 0,3 m.daN.
Reposer : Le réservoir d’additif de carburant .
2.2. Côté droit
Positionner : Barre de renfort (3).
Reposer la vis ((2)).
Serrer les vis (2), (4) à 1,1 ± 0,3 m.daN.
2.3. Repose (suite)
Reposer : Le ressort de suspension .
Contrôler le parallélisme (régler si nécessaire).
