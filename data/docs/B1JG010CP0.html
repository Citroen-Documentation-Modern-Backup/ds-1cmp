2. Repose
Figure : b1jm028d
Vérifier : La planéité du plan de joint du collecteur d’échappement ; À l’aide d’une règle et d’un jeu de jauges d’épaisseur ( en "a").
Valeur limite : 0,7 mm .
Reposer :
  • Le joint (16) (Neuf)
  • Le collecteur d’échappement (15) équipé de l’écran thermique inférieur
IMPERATIF : Remplacer l’ensemble : écrous /[/] rondelles (14)/ joint (16).
Approcher les écrous (14) (neufs).
Reposer : L’écran thermique supérieur .
Serrer les écrous (14) ; Serrer au couple.
Reposer :
  • Les vis (13) ; Serrer au couple
  • La patte de levage (11)
  • L’écran thermique (Tablier compartiment moteur) (10)
  • La barre antirapprochement (12)
ATTENTION : Respecter les couples de serrage.
Lever le véhicule.
ATTENTION : S’assurer que les vis (9) sont en contact avec le carter cylindres avant le serrage de la vis (8).
Reposer :
  • Le grand support du collecteur d’échappement
  • Les vis (9), (8) ; Serrer au couple
  • Le petit support du collecteur d’échappement
  • Les vis (7) ; Serrer au couple
IMPERATIF : Remplacer : Les joints (1), (3).
IMPERATIF : Remplacer impérativement la vis (2) et les écrous (4).

  • Les vis (2) (neuves) (Tube de descente avant) ; Serrer au couple
  • Les écrous ((/)) (neufs)
