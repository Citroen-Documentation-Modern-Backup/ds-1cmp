B1JG016UP0Dépose - Repose : Collecteur d’échappement
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie .
Lever et caler le véhicule.
Déposer la protection sous moteur .
Figure : b1jm024d
Déposer :
  • La traverse (5)
  • Les vis (2)
  • Les écrous (4)
  • Les joints (1), (3)
  • Le tube de descente avant (6)
Figure : b1jg0e3d
Déposer :
  • Les vis (8)
  • Le support du collecteur d’échappement (7)
Figure : b1jg0e6d
Déposer :
  • La barre antirapprochement (12)
  • L’écran thermique (10)
  • La patte de levage (11)
  • Les vis (9)
Figure : b1jg0e7d
Soulever : L’écran thermique supérieur .
Déposer :
  • Les ensembles écrous/rondelles (13)
  • Le collecteur d’échappement équipé des écrans thermiques
  • Le joint de collecteur d’échappement
2. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1jg0ead
Vérifier : La planéité du plan de joint du collecteur d’échappement ; À l’aide d’une règle et d’un jeu de jauges d’épaisseur (en "a").
Valeur limite : 0,7 mm .
Reposer :
  • Le joint de collecteur d’échappement neuf (15)
  • Le collecteur d’échappement (14) équipé de l’écran thermique inférieur
ATTENTION : Remplacer les ensembles écrous / rondelles (13) et les joints (15).
Approcher : Les ensembles écrous/rondelles (13) (neufs).
Reposer : L’écran thermique supérieur .
Serrer : Les ensembles écrous/rondelles (13) ; Serrer au couple.
Reposer :
  • Les vis (9) ; Serrer au couple
  • La patte de levage (11)
  • L’écran thermique (10)
  • La barre antirapprochement (12)
Lever le véhicule.
ATTENTION : S’assurer que les vis (8) sont en contact avec le carter- cylindres avant le serrage des vis sur le collecteur d’échappement.
Reposer :
  • Le support du collecteur d’échappement (7)
  • Les vis (8)
ATTENTION : Remplacer : Les joints (1), (3).
ATTENTION : Remplacer impérativement la vis (2) et les écrous (4).
Reposer :
  • Les joints (1) et (3) (neufs)
  • Le tube de descente avant (6)
  • Les vis (2) (Neuves)
Resserrer les vis (2) au couple.
Reposer :
  • Les écrous (4) (neufs)
  • La traverse (5)
  • La protection sous moteur
Reposer le véhicule sur ses roues.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
