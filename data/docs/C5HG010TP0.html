2. Opérations préliminaires

Déposer la planche de bord .
Vidanger le circuit de réfrigération .

3.3. Opérations communes
Figure : c5hm03td
Déposer vis (8).
ATTENTION : Obturer rapidement tous les conduits afin d’éviter l’introduction d’humidité ; À l’aide des outils [3].
Écarter les tuyaux de réfrigération (9).
Figure : c5hm03ud
Dépressuriser le circuit de refroidissement.
Mettre en place les outils [1] sur les durits (12).
Déposer les clips de verrouillage (10).
Désaccoupler : Les durits de refroidissement (12).
NOTA : Évacuer un maximum de liquide de refroidissement de l’aérotherme à l’aide d’une soufflette placée en entrée. Placer un récipient pour récupérer le liquide de refroidissement.
Déposer le caoutchouc d’étanchéité (11).
Figure : c5hm03vd
Déposer les 2 écrous (13).
Figure : c5hm03wd
Déposer les 3 écrous (15).
Désaccoupler : Le tuyau d’évacuation des condensats .
Déposer le groupe de chauffage (14).
4. Repose
Reposer le groupe de chauffage (14).
Accoupler : Le tuyau d’évacuation des condensats .
Reposer :
  • Les 3 écrous (15)
  • Les 2 écrous (13)
  • Le caoutchouc d’étanchéité (11)
Accoupler : Les durits de refroidissement (12).
Reposer les clips de verrouillage (10).
Enlever les outils [1].
Effectuer une mise à niveau et une purge du circuit de refroidissement.
Reposer :
  • Tuyaux de réfrigération (9)
  • vis (8) ; Serrer à 0,49 ± 0,09 m.daN
Effectuer :
  • Un tirage au vide du circuit de réfrigération (pendant 15 minutes minimum)
  • Un contrôle d’étanchéité du circuit de réfrigération
