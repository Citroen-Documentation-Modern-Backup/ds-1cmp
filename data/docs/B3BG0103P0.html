B3BG0103P0Dépose - Repose : Ensemble ressort - amortisseur avant
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Débloquer les écrous de roues (Avant).
Lever et caler le véhicule roues pendantes.
Déposer la roue avant.
Figure : b3bm00gd
Déposer l’écrou (1).
Désaccoupler la biellette (2).
Déposer l’écrou (3).
Écarter : Le support de flexible (4).
Figure : b3bm00hd
Déposer les écrous (5).
Figure : b3bm00jd
Déclipper le support faisceau (6).
NOTA : Maintenir la transmission emboîtée dans la boîte de vitesses.
Déposer :
  • Les vis (7)
  • L’ensemble ressort amortisseur avant
2. Repose
Reposer :
  • L’ensemble ressort amortisseur avant
  • Les vis (7) ; Serrage à 11,0 ± 1,1 m.daN
  • Le support faisceau électrique (6)
  • Les écrous (5) ; Serrage à 4,5 ± 0,7 m.daN
  • Le support de flexible (4)
  • L’écrou (3) ; Serrage à 1,1 ± 0,2 m.daN
Accoupler la biellette (2).
Reposer l’écrou (1) ; Serrage à 3,9 ± 0,6 m.daN.
Reposer la roue avant.
Reposer le véhicule sur ses roues.
Serrer les vis de roues .
