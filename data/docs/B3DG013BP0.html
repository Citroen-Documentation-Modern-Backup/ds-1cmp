ATTENTION : Respecter les couples de serrage.

  • Train arrière
  • Système de freinage
  • roues

  • Les vis (12)
  • Les vis (11)
  • Les vis (10)

NOTA : Pour reposer les vis (11), modifier le réglage de parallélisme (si nécessaire).

  • Le capteur de roue (8)
  • La vis (7)
  • La vis (9)
3.1. Véhicules équipés de lampe xénon

Reposer l’écrou (6).

Engager (de chaque côté) :

  • Le câble de frein de stationnement (2) du plateau de frein

Reposer :
  • Les moyeux roulement arrière
  • L’ensemble tuyau intermédiaire / silencieux arrière d’échappement (1)

Reposer les roues arrière.
Serrer les vis de roues.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
