C5GG010AP0Dépose - repose : Garniture de pavillon
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage
outil Référence Désignation
Figure : e5ag071t
 [1350-ZZ] Outil de dégarnissage
2. Opérations préliminaires
Avancer les sièges avant en position maximum .
Mettre les sièges avant en position allongée.
Rabattre les dossiers de sièges arrière.
Déposer :
  • Les garnitures supérieures de pied de milieu
  • Les garnitures de montant de baie
  • Les garnitures supérieures de custode  (arrière)
  • Le joint de coffre (1) (partiellement)
3. Dépose
Figure : c5gm07nd
Abaisser la poignée de maintien (4).
Déclipper les caches articulés (2); À l’aide d’un petit tournevis.
Déposer :
  • Les vis (3)
  • La poignée de maintien (4)
Procéder à l’identique pour les autres poignées de maintien.
Déclipper : Le cache (7) des éclaireurs de pavillon (6); À l’aide de l’outil [1350-ZZ].
Déposer :
  • La vis (5)
  • Les éclaireurs (6) de pavillon
Figure : c5gm07pd
Déclipper et déposer Le support porte-lunette (suivant équipement).
Déclipper : La console d’éclairage avant (12); À l’aide de l’outil [1350-ZZ].
Déconnecter les connecteurs  (en "a").
Déposer :
  • La console d’éclairage avant (12)
  • Les vis (9)
  • Les pare-soleil (10)
Déclipper les crochets (11).
Déposer le crochet (11).
Déclipper les pions ((8)).
Figure : c5gm04ad
Déclipper : La garniture de lecteur de DVD-ROM (13) (en "b") ; À l’aide de l’outil [1350-ZZ] (Suivant équipement).
Déposer : La garniture de lecteur de DVD-ROM (13)(Suivant équipement).
Figure : c5gm04bd
Déclipper les pions (14).
Déposer :
  • Les pions (14)
  • La garniture de pavillon (15)
4. Repose
Contrôler l’état des agrafes, et remplacer si nécessaire.
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Reposer :
  • La garniture de pavillon (15)
  • Les pions (14)
Pour les opérations suivantes procéder dans l’ordre inverse des opérations de dépose.
5. Opérations complémentaires
Reposer :
  • Les garnitures supérieures de pied de milieu
  • Les garnitures de montant de baie
  • Les garnitures supérieures de custode  (arrière)
  • Le joint de coffre (1) (partiellement)
Vérifier le fonctionnement électrique des équipements.
NOTA : Nettoyer la garniture de pavillon avec de l’eau et du savon (si nécessaire).
