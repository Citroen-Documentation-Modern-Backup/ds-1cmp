"A" Épaisseur du poussoir neuf
"B" Épaisseur de l’ancien poussoir
"C" Jeu aux soupapes mesuré
Soupapes d’admission : "A" = "B" + ("C" - 0,20 mm).
Soupapes d’échappement : "A" = "B" + ("C" - 0,30 mm).

4. Vérification des déphaseurs d’arbres à cames
4.1. Vérification du déphaseur (côté échappement)
NOTA : Cette opération est applicable selon équipement (avec ou sans déphaseur d’échappement).
Figure : b1bg2khd
Dégraisser l’extrémité de l’arbre à cames échappement.
Obturer à l’aide d’un ruban adhésif (en "f") :
  • Les orifices de retard (en "d")
  • Les orifices d’avance (en "e")
Percer l’un des 2 orifices de retard (en "d").
NOTA : Enrubanner l’extrémité de l’arbre à cames par 2 tours de ruban adhésif.
Figure : b1bg2kid
Maintenir l’arbre à cames à l’aide d’une clé (en "g").
Reposer le déphaseur d’échappement (4).
Figure : b1bg2kjd
Maintenir l’arbre à cames échappement dans un étau à mords doux (en "g").
Appliquer une pression d’air (en "d") pour déverrouiller le déphaseur d’arbre à cames (4).
Le déphaseur (4) doit pouvoir être tourné à la main dans les 2 sens de rotation ; Aucun point dur ne doit être perceptible.
NOTA : La rotation du déphaseur d’échappement (4) est d’environ 10°.
Relâcher la pression (en "d").
Le ressort de rappel doit verrouiller le déphaseur dans le sens horaire.
En cas de grippage ou de mauvais verrouillage : Remplacer le déphaseur d’arbre à cames.
ATTENTION : Après contrôle : Déposer le ruban adhésif  (en "f").
4.2. Vérification du déphaseur (côté admission)
Figure : b1bg2kkd
Dégraisser l’extrémité de l’arbre à cames admission.
Obturer à l’aide d’un ruban adhésif (en "k") :
  • Les orifices d’avance (en "h")
  • Les orifices de retard (en "j")
Percer l’un des 2 orifices d’avance (en "h").
NOTA : Enrubanner l’extrémité de l’arbre à cames par 2 tours de ruban adhésif.
Figure : b1bg2kld
Reposer le déphaseur d’admission sur l’arbre à cames.
Maintenir l’arbre à cames admission dans un étau à mors doux (en "g").
Appliquer une pression d’air (en "h") pour déverrouiller le déphaseur d’arbre à cames (5).
Le déphaseur (5) doit pouvoir être tourné à la main dans les 2 sens de rotation sans points durs.
NOTA : La rotation du déphaseur d’admission (5) est d’environ 12,5°.
Relâcher la pression (en "h").
Tourner le déphaseur jusqu’en butée dans le sens horaire : Le déphaseur doit se verrouiller.
En cas de grippage ou de mauvais verrouillage : Remplacer le déphaseur d’arbre à cames.
ATTENTION : Après contrôle : Déposer le ruban adhésif  (en "k").
