B3FG010FP0Dépose - repose : Câbles de frein de stationnement
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Débloquer les écrous de roue (Arrière ).
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • Les écrous ((/)) (Roues arrière)
  • Les roues arrière
Desserrer le frein de stationnement .
Déposer :
  • La console centrale arrière
  • Les disques de freins arrière
  • Les moyeux arrière
  • Les segments de frein de stationnement
Figure : b3fm01jd
Desserrer l’écrou (1).
Positionner l’écrou (1) à l’extrémité du filetage de la tige (2)(en "a").
Désaccoupler :L’extrémité des câbles de frein de stationnement (3)(en "b").
Dégager des guides les câbles de frein de stationnement (3) (en "c").
Figure : b3fm01kd
Déposer (de chaque côté) :
  • Les écrous ((/))
  • Le protecteur (5)
Figure : b3fm01ld
Déposer l’écrou (6) (de chaque côté).
Figure : b3fm01md
Déposer (de chaque côté) :
  • La vis (7)
  • La vis (8)
  • L’agrafe (9)
Dégager le câble de frein de stationnement (3) du plateau de frein.
Figure : b3fm01nd
Effectuer les opérations suivantes (de chaque côté) :
  • Soulever : Le tapis de plancher arrière
  • Dégrafer : Le câble de frein de stationnement (3) (en "d")
  • Déposer : Le câble de frein de stationnement (3)
2. Repose
Reposer : Les câbles de frein de stationnement (3).
Engager les câbles de frein de stationnement (3) dans leurs guides(en "c").
Accoupler : L’extrémité des câbles de frein de stationnement (3)(en "b").
Effectuer les opérations suivantes (de chaque côté) :
  • Engager le câble de frein de stationnement (3) dans le plateau de frein
  • Agrafer : Le câble de frein de stationnement (3) (en "d")
Reposer (de chaque côté) :
  • L’écrou (6)
  • La vis (7)
  • La vis (8)
  • L’agrafe (9)
  • Le protecteur (5)
  • Les écrous ((/))
Reposer :
  • Les segments de frein de stationnement
  • Les moyeux arrière
  • Les disques de freins arrière
Régler le frein de stationnement .
Reposer :
  • La console centrale arrière
  • Les roues arrière
  • Les écrous ((/)) (Roues arrière)
Serrer : Les écrous de roues à 10 ± 1 m.daN.
