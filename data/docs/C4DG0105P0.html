C4DG0105P0Dépose - repose : Console de pavillon
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap30wd
[1] Outil de dégarnissage (-).1350-ZZ.
2. Dépose
Effectuer les opérations suivantes :
  • Couper le contact
  • Attendre 3 minutes avant de débrancher la batterie
  • Débrancher la batterie
2.1. Console de pavillon
Figure : c5em00sd
Déclipper la console de pavillon (1) (en "b") ; À l’aide de l’outil [1].
Déconnecter les connecteurs  (en "a") (suivant équipement).
Déposer la console de pavillon (1).
2.2. Caches éclairages
Figure : c5em00td
Déclipper : Caches éclairages (2)(en "c") ; À l’aide de l’outil [1].
Déposer : Caches éclairages (2).
2.3. Cache
Figure : c5em00ud
Déclipper le cache (3) (en "d") ; À l’aide de l’outil [1].
Déposer le cache (3).
2.4. Commande : Éclairage
Figure : c5em00vd
Déclipper : La commande d’éclairage (4) (en "e").
Déposer : La commande d’éclairage (4).
2.5. Commande de toit ouvrant (suivant équipement)
Figure : c5em00wd
Déclipper : Commande de toit ouvrant (5)(en "f") ; À l’aide de l’outil [1].
Déposer : Commande de toit ouvrant (5).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Brancher la batterie.
Réaliser les opérations à effectuer après un rebranchement de la batterie.
Vérifier le fonctionnement des équipements électriques.
