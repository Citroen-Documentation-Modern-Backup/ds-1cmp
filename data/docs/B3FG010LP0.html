B3FG010LP0Dépose - repose : Segments de frein arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5am054d
[1]Outil FACOM D.104 de dépose-repose coupelles de ressorts de segments de frein.
2. Dépose
Débloquer les écrous de roues(Arrière ).
Lever et caler le véhicule, roues arrière pendantes.
Desserrer le frein de stationnement .
Déposer :
  • Les écrous (Roues arrière)
  • Les roues arrière
  • Les disques de freins arrière
  • Les moyeux arrière

Déposer :
  • Les vis (1)
  • La chape d’étrier de frein(2)
Figure : b3fm024d
Déposer :
  • Le ressort (3)
  • Le mécanisme de réglage (4)
  • Le ressort (5)
  • Le ressort (6)
Figure : b3fm025d
Déposer :
  • La plaque (7)
  • Le support (8) équipé de son ressort
  • L’ensemble coupelles et ressorts (9); À l’aide de l’outil [1]
  • Le segment de frein arrière(10)
Désaccoupler: Le câble de frein de stationnement (12) du segment de frein (11).
Déposer: Le segment de frein arrière(11).
3. Repose
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
3.1. 1ère possibilité
Nettoyer le disque de frein, l’étrier de frein et le plateau de frein;À l’aide d’un produit nettoyant frein recommandé.
Laisser égoutter et sécher.
Essuyer à l’aide d’un chiffon papier.
3.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué par le constructeur .
4. Repose
Figure : b3fm026d
Appliquer un point de graisse ( en "a", "b", "c", "d", "e" ) ; Utiliser une graisse homologuée par le constructeur.

Reposer :
  • Le segment de frein arrière(11)
  • Le segment de frein arrière (10)
  • L’ensemble coupelles et ressorts (9); À l’aide de l’outil [1]

NOTA : Nettoyer parfaitement les faces d’appui disque/moyeu.
Reposer :
  • Les moyeux arrière
  • Les disques de freins arrière
Régler le frein de stationnement .
ATTENTION : Donner plusieurs coups de frein, moteur en marche, avant de faire rouler le véhicule.
Vérifier le fonctionnement des freins.
Reposer :
  • Les roues arrière
  • Les écrous (Roues arrière)
Remettre le véhicule sur ses roues.
Serrer les vis de roues .
