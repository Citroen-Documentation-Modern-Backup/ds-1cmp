B3BG0108P0Dépose - repose : Barre antidévers arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Caler et lever le véhicule sur un pont élévateur à 2 colonnes.
Déposer les roues arrière.
Figure : b1jm017d
ATTENTION : Maintenir le filtre à particules (FAP) en position. Ne pas déformer axialement ou angulairement les tubes flexibles avant du filtre à particules. Le non-respect de ces précautions entraîne une diminution de la durée de vie du tube flexible avant.
Déposer :
  • Le tuyau d’échappement (1) (Intermédiaire)
  • Le réservoir d’additif de carburant
  • Le pont arrière
Figure : b3bm010d
Déposer les écrous (2).
Désaccoupler les biellettes (3) de la barre antidévers.
Déposer :
  • Les vis (4)
  • Les barres de renfort (5)
Figure : b3bm011d
Déposer :
  • Les vis (6)
  • Les supports paliers de barre antidévers arrière (7)
  • La barre antidévers arrière
2. Repose
Figure : b3bm012d
ATTENTION : Respecter le positionnement des paliers de barre antidévers arrière.
Positionner les paliers de barre antidévers (8) vers l’extérieur des bagues "a".
Reposer :
  • La barre antidévers
  • Les supports de paliers de barre antidévers (7)
  • Les vis (6)
Serrer les vis (6) à 3,1 ± 0,4 m.daN.
Reposer :
  • Les barres de renfort (5)
  • Les vis (4) ; Serrer à 1,1 ± 0,3 m.daN
Accoupler les biellettes (3) sur la barre antidévers.
Reposer les écrous (2) ; Serrer à 3,9 ± 0,6 m.daN.
Reposer :
  • Le pont arrière
  • Le réservoir d’additif de carburant
  • Le tuyau d’échappement (1) (Intermédiaire)
  • Les roues arrière
Serrer les vis de roues .
Contrôler le parallélisme (régler si nécessaire).
